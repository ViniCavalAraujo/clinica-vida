# Clínica Vida

Projeto desenvolvido para prática de JavaScript, incluindo validação de formulários, manipulação de JSON, consumo de dados com Fetch API e integração com API externa para consulta de CEP.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* JSON
* Fetch API

## Funcionalidades

* Validação de formulário de agendamento
* Carregamento de profissionais através de arquivo JSON
* Consumo de API externa para consulta de CEP
* Layout responsivo
* Menu de navegação adaptado para dispositivos móveis
